# 包装灵感库 (Packaging Inspiration Library)

一个记录打动你的包装结构、外观与开箱体验的工具，日后设计时随时翻找参考。

## 特性

- 拍照录入，多角度照片（正面/侧面/开箱/内衬等）
- 结构化字段：盒型、尺寸、内衬结构、材料（含环保标注）、外观风格、开箱体验、灵感备注、产品品类
- 刀模文件上传（PDF/JPG，前期手动传，后期考虑优化为按尺寸自动生成）
- 检索：条件组合筛选（盒型/材料/品类/风格）+ 关键词搜索 + 日期范围
- 两种模式：本地编辑模式（手机和电脑都能录入）/ 静态只读画廊（发布给同事浏览）

## 使用方式

### 本地编辑模式

    npm start

或直接：

    node server.js

启动后浏览器打开 http://localhost:3000 。手机连同一 WiFi，访问 http://<电脑IP>:3000 即可边拍边录。

### 发布只读画廊

数据以 JSON + 图片文件形式存在仓库里。推送到 GitHub 后，用 GitHub Pages 部署，同事拿到公开链接即可只读浏览，不能编辑。

## 数据自有

所有数据存在本地仓库的 data/entries.json 和 images/ 目录下，不依赖任何云服务。git 提交历史本身就是从 0 到 1 的迭代记录。

## 技术栈

纯 Node.js（内置 http 模块，零依赖）+ 原生 HTML/CSS/JS，与装箱工具风格一致。
